# Employee Churn Analysis

##  Problem Statement
Employee attrition is a major challenge for organizations, leading to increased hiring costs and productivity loss. This project analyzes employee data to identify the key factors that contribute to churn.

##  Objective
To uncover patterns behind employee turnover and help HR teams take data-driven actions to improve retention.

## Tools & Technologies
- Python
- Google Looker Studio
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook


##  Analysis Performed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Correlation analysis between job factors and attrition
- Visualization of high-risk employee segments

## Key Insights
- Employees working overtime showed a higher churn rate  
- Low job satisfaction strongly correlated with attrition  
- Salary band and job role influenced retention trends  

##  Business Recommendations
- Monitor workload and reduce excessive overtime  
- Improve employee engagement programs  
- Review compensation for high-risk departments  

## Outcome
This project demonstrates how data analysis can support HR decision-making and reduce employee turnover.
